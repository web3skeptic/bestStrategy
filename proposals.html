3D model rework — three proposals

Each row: CURRENT models the game renders today (left) next to PROPOSED prototypes (right). Nothing is wired into the board yet.

What each proposal changes

1 · Faction body kits. Today Temple and Agrar humanoids are the same Voxel Guy with a swapped weapon; only the torso tint says whose it is. Proposed: a hooded nomad robe for Temple, a broad straw-hat farmer for Agrar, with the team colour moved to a sash/apron so faction and owner both read at a glance.

2 · Tile set v2. Bevelled two-tone rims, calmer plains, mixed conifer/broadleaf forests with undergrowth, terraced hills with rock outcrops, and jagged snow-capped mountain clusters instead of one cone.

3 · Structure set v2. One 10-level ziggurat currently stands in for Ruins, founding, Temple I/II and the Capital. Proposed: real Ruins, an open-pillar Temple I, a two-storey Temple II with banners, and a walled keep for the Capital.
