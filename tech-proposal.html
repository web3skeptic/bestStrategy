What changes

  • It becomes a tree. Today five headed lists of chips; the prerequisites exist only as italic text. Proposed: lanes (Siege, Heavy Unit, Command, Stat Bonus, Support) × tiers (Foundation → Advanced → Elite) with drawn connectors, so "Champion needs Warrior Rite and Command I" is a line you can see, not a sentence you have to read.
  • Compact nodes, one detail pane. Every chip currently repeats its full description and status; the panel scrolls on phones. Proposed nodes are a medallion + name + cost/time; click (or hover) a node and the pane below shows the description, prerequisites with ✓/✗, and one clear Research button. Fewer accidental purchases too, since the card itself is no longer the buy button.
  • State on the ring, not the whole card. Cyan glow = available, teal ✓ = researched, amber conic ring filling up = researching (with rounds left), dim + lock = blocked, orange cost = can't afford. The one research slot gets a status bar at the top instead of a text line.
  • "Choose one" is a visible bracket. Pick-one branches are grouped in a dashed frame labelled choose one, which flips to choice made once picked, replacing the "✓ Choice made — branch locked" caption.
  • Same palette as the rest of the HUD. Gold title, slate panel, cyan/teal/amber semantic colours already used elsewhere; drops the chiselled-rock clip-paths that don't match the 3D board's look.

Implementation footprint if accepted: renderTechTree/appendSection in src/main.ts (~150 lines), the tech CSS block in index.html, plus a ~40-line SVG connector routine. Game logic untouched.
